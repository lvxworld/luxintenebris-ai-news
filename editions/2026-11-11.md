## Lead Machine-checked security: DeepMind's AlphaProof Code proves Signal's protocol secure from the compiled code up

A multi-LLM agentic framework produced a machine-checked Lean proof of key security properties of the actual compiled code behind the Signal protocol, generating more than six million lines of Lean in about four weeks. Reintroducing two previously fixed bugs into an isolated copy produced proofs that the buggy versions were insecure. DeepMind says the same work would have taken expert teams years.

Source: [Google DeepMind](https://deepmind.google/blog/introducing-alphaproof-code/)

## Research & Papers

- **[ReTrace distils tool-using agents into planner-free workflows](https://arxiv.org/abs/2611.14492)** — Converting an SOP plus a few logged agent runs into an executable workflow where code, not an LLM, picks each next step reaches 93.8% completion on 79 production procedures versus 96.8% for the agent, at 24% lower cost per task. On tau2-Bench it scores 75.8% at 1.3 seconds per run against 170 seconds for the agent. *(arXiv)*
- **[Contrastive Discovery tests competing explanations instead of single hypotheses](https://arxiv.org/abs/2611.14514)** — Scoring experiments by how they redistribute belief across mutually exclusive explanations resolves 67% more questions than pointwise surprisal at an equal experiment budget, and resolves 73% of candidates to a specific alternative. Blinded experts agreed with the chosen explanation on 78% of resolved questions across six domains. *(arXiv)*
- **[Microsoft harness lifts Llama-3-8B by 64 points on long-context tasks with no training](https://x.com/omarsar0/status/2120160305347260443)** — The method decomposes long-context tasks into capability primitives, then has a strong agent iteratively rewrite the harness, state tracking and control logic. Llama-3-8B gains 64.18 points on average with zero post-training, the harness transfers to Qwen2.5-3B, and it beats data-heavy trained approaches at roughly half the cost. *(@omarsar0)*
- **[Massive activations make sparse autoencoder features unstable](https://arxiv.org/abs/2611.13548)** — Up to 99.9% of activation variance sits on the first principal component, which has no unique sparse decomposition, so 47 of the top 50 features fail to match across runs and a dictionary can claim 99.96% variance explained while leaving a third of off-PC1 variance unexplained. Training on PC1-removed activations raises top-50 feature sharing from 4-39.5% to 73-99.5%. *(arXiv)*
- **[Sugar Glider keeps a fixed-size KV cache past a million tokens](https://x.com/omarsar0/status/2120142218316964143)** — i14 Labs' architecture family maintains constant cache size as context grows beyond 1M tokens, delivering up to 32x more requests per server than baseline. Memory size is chosen at deployment without retraining, removing the need for constant summarisation in long-running agents. *(@omarsar0)*

## Open Source & Models

- **[MiniMax releases H3-Image as open weights: 33.1B, 16-megapixel generation and editing in one checkpoint](https://news.sulat.com/2026/11/11/minimax-releases-h3-image-open-weights/)** — A 33.1B diffusion transformer derived from the H3 family with the audio layers removed, generating roughly 16-megapixel images in six distilled sampling steps with no classifier-free guidance, with text-to-image and editing sharing one set of weights. The licence excludes the EU, UK, South Korea and the US and requires written authorisation for hosted services or revenue above $1M; native ComfyUI support merged the same day. *(Sulat AI & Tech News)*
- **[Zyphra ships ZONOS3-Mini, an Apache-2.0 TTS model with 100M active parameters](https://www.marktechpost.com/2026/11/10/zyphra-zonos3-mini-open-source-tts/)** — A sparse MoE text-to-speech model with 800M total and about 100M active parameters, a 32,768-position context and up to ten minutes of audio per generation, plus zero-shot cloning and word-level control over pace, emotion and accent. Zyphra reports 80 ms median time to first audio on one H100 with eight concurrent requests. *(MarkTechPost)*
- **[Hugging Face makes decision models a first-class pipeline](https://huggingface.co/blog/decision)** — The new pipeline("decision") interface scores a state against questions defined at runtime and returns a calibrated probability distribution instead of generating tokens. Training support for decision heads is in an open TRL pull request, and Unsloth published a LoRA recipe for turning existing Qwen models into decision models. *(Hugging Face Blog)*
- **[QVAC and Tether ship BotPsy-0.8B, an on-device model built for tool calling](https://huggingface.co/blog/qvac/botpsy)** — A 0.8B fine-tune of Qwen3.5-0.8B for function calling and agentic workflows, with BF16 safetensors plus a separate GGUF repository for llama.cpp and the QVAC SDK. It claims state-of-the-art tool use below 1.2B parameters while warning that it suits low-to-medium difficulty tasks only. *(Hugging Face Blog)*
- **[TNG shows how to graft new experts into a trained MoE without retraining it](https://huggingface.co/blog/tngtech/bring-your-own-expert-extending-moe-models-with-ne)** — Instead of fine-tuning existing experts and degrading what the model already knew, the recipe adds brand-new experts so a mixture can absorb a domain it never saw. The walkthrough uses Qwen3.5-35B-A3B-Base with a code dataset and releases the resulting chimera checkpoint. *(Hugging Face Blog)*
