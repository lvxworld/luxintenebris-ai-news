## Research & Papers

- **[Stable Gated DeltaNet-2 fixes recurrent state instability in long-context training](https://huggingface.co/papers/2611.34051)** — Traces Gated DeltaNet-2 failures to asymmetric erasure operators whose directional gains compound across tokens, and fixes them with symmetric erasure plus decay-regulated residual writing. At ~1.6B parameters it raises the 128K RULER average by 6.80 points. *(HuggingFace)*
- **[OS-Omni benchmarks generalist computer-using agents on long-horizon workflows](https://huggingface.co/papers/2611.34232)** — A live benchmark spanning six platforms with tasks averaging 67.54 interaction steps. Best agent (Claude Opus 5.5) reaches 68.5% success against a 77.3% human reference, trailing humans by 25+ points on iOS and macOS. *(HuggingFace)*
- **[Yandex releases AliceAI-Foundation-80B-A3B-Base under Apache 2.0](https://arxiv.org/abs/2611.34529)** — An 80B-total, ~3B-active MoE base model trained from scratch on 17.5T tokens with Kimi Delta Attention, Attention Residuals and Muon, with architecture ablations and scaling-law experiments included. *(arXiv)*
- **[ShowNow: speculative streaming keeps responsive world models at 480p/16fps on one H100](https://huggingface.co/papers/2611.34693)** — Uses playback-idle compute to prepare action-conditioned futures with single-latent commitment and shared-history tree execution, cutting median input-to-display latency from 620 ms to 208 ms on ViZDoom. *(HuggingFace)*
- **[vSFT learns to verbally tune agents at test time](https://arxiv.org/abs/2611.34440)** — A supervisor turns an agent's failed trajectories into natural-language feedback that a hypernetwork converts into low-rank weight updates at inference time, beating GRPO and Reflexion by 8.7% on agentic tasks. *(arXiv)*
- **[DRBench Pro scores deep research agents on knowledge coverage](https://huggingface.co/papers/2611.34852)** — A benchmark of 144 cases across 24 domains with 44,102 evidence-grounded rubrics; the best of 16 deep research agents reaches 57.04% overall coverage. *(HuggingFace)*

## Open Source & Models

- **[Sber's GigaChat 4 open weights resurface: 708B/41B-active and 37B/4B-active MoEs](https://huggingface.co/collections/ai-sage/gigachat-4)** — The first fully open release from Russia's frontier-model ecosystem is drawing fresh attention: a 710B MoE with 41B active under MIT and a 38B/4B-active sibling, both with GGUF and bf16 variants. Checkpoints landed Nov 20 but the collection resurfaced Nov 26. *(Hugging Face)*
- **[NVIDIA opens the Nemotron 3.5 Parse recipe: 19M synthetic samples and a DFlash2 speculator](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin)** — Three training datasets (9.98M synthetic charts, 1M tables, 7.9M multilingual OCR pages), an NeMo SFT+GRPO recipe, and a draft model that lifted single-pass throughput 7.62x on one H200. GRPO cut loop-flagged pages by ~77% over SFT alone. *(Hugging Face)*
- **[Z.ai says GLM-5.5 is not delayed, still targeting a December open-weights launch](https://reddit.com/r/LocalLLaMA/comments/1y6260i/zai_clarifies_glm55_has_not_been_delayed/)** — Z.ai publicly clarified its next flagship has not slipped after community chatter, confirming a December window that r/LocalLLaMA reads as the last major open-weights drop of the year alongside Kimi K3.1 and DeepSeek V4.1. *(Reddit r/LocalLLaMA)*
- **[ISTA-DASLab ships non-uniform GGUF quants: Inkling-2-Mini at 3.5 bpw keeps 99.2% of base](https://huggingface.co/ISTA-DASLab/Inkling-2-Mini-GSQ-RCO-GGUF)** — GSQ-RCO GGUFs at 2.75–3.5 bits per weight assign a separate quantization type to each of 169 tensors via a budget-constrained Riemannian search; the recommended IQ3_S build lands within one point of the BF16-class base on AIME25, GPQA-Diamond and LiveCodeBench v6. *(Hugging Face)*
- **[Nullify 68M: local PII detection at 8.5 ms per message](https://huggingface.co/rbsriram/nullify-68m)** — A 68M-parameter token classifier scores 86.6 F1 on Privacy-Bench, ahead of the OpenAI Privacy Filter 1.5B (73.3) and GLiNER2 PII (84.6). Apache 2.0, ONNX or PyTorch, ~0.7 GB of memory, built as a local redaction filter in front of cloud LLM calls. *(Hugging Face)*
- **[ggml publishes a public llama.cpp benchmark dashboard for AMD Ryzen and Radeon](https://huggingface.co/blog/ggml-org/llamacpp-amd-bench)** — Tracks PP512 and TG128 throughput across builds, models and quantizations for Radeon 8060S and AI Pro R9700S, refreshed by weekly GitHub Actions runs, with bench data readable from a public storage bucket. *(Hugging Face)*

## Tools & Startups

- **[Moat by Command Code: a $5/mo subscription alternative to per-token model routing](https://commandcode.ai/moat)** — Moat pools subscribers' usage to buy frontier models at wholesale prices, offering 40–70% off models such as GLM-5.3, DeepSeek V4.1 Flash and Kimi K3. HN commenters note the subscription model is not a drop-in replacement for pay-per-token routing. *(Command Code)*
- **[minipg: PostgreSQL as a single executable](https://github.com/progrium/minipg)** — Runs Postgres 18 Alpine as one executable with no Docker, VM or Linux kernel — the database lives in a portable .pgdb directory and the server starts on demand. The author warns it is roughly 2x slower than native and early-stage. *(GitHub)*
- **[Fleetify: open-source command center for AI coding agents](https://www.producthunt.com/products/fleetify)** — A free desktop app for running Claude Code, Codex, OpenCode and seven other agents side by side, with status, spend, tokens and live activity per session; each task gets its own git worktree, dev-server preview and PR. *(Product Hunt)*
- **[AgentDesign: make your coding agent draw every screen before it writes code](https://getagentdesign.com/)** — A macOS review app has Claude Code, Codex or Cursor generate screen designs first, letting developers annotate and approve before any code is written; every version is kept as plain files locally. Free unlimited demo, $29 one-time license. *(AgentDesign)*
- **[Kaju: annotate, comment and collaborate with Claude Code in the terminal](https://github.com/aigeano/kaju)** — Select text in Claude Code's terminal output, hit a hotkey and send a quoted comment straight back to the agent, or collect comments and send them as one numbered review. Makes no network connections. *(GitHub)*
