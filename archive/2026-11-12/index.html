Tree-Ising repairs language models with bit-level Ising edits

Casts weight repair as sparse discrete optimization, splitting it into per-row QUBO problems solved by GPU simulated annealing. On the two layers MIT's GPT-6 Astra agent targeted it reaches 54.6% on MATH-500 versus 51.7%, flipping 2.2 to 2.3 times fewer bits with four forward passes and zero LLM tokens.

Are dense rewards worth their tokens in GRPO?

A matched-compute protocol equalizing tokens and GPU-hours across 1,668 runs reverses the usual ranking of dense process rewards. On Qwen2.5-1.5B the Monte-Carlo reward leads per update but ends 14.3 points lower at equal tokens and 7.8 points lower at equal training time.

Hugging Face · 2026-11-10

Robot memory policies treat elapsed time as progress

Memory-augmented VLA policies index memory by clock time, so a task-irrelevant pause reads as progress and triggers early stopping: success drops from 47/50 to 16/50 on one RoboMME counting task. Event-based memory indexing recovers half or more of the loss without retraining.

Hugging Face · 2026-11-10

A frozen robot policy learns new tasks by rehearsing them in a simulator

WICL has a frozen model rehearse a demonstrated task in simulation and write the resulting world feedback into context instead of weights. RoboScript reaches 83.4% mean success on all 50 RoboTwin 2.0 tasks from a single demonstration with no gradient updates, and transfers to a physical dual-arm robot.

Hugging Face · 2026-11-09

LLMs can build valid world models that are still wrong

A 44-scenario benchmark tests whether five LLMs can write formal world models as partially observable stochastic games. 134 of 135 generations pass a strict mechanical audit, but mean structural F1 against authored references is only 0.366 and just 28 match exactly.
