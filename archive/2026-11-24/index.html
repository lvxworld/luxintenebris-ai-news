GLM-5.4 runs roughly 750B parameters by looping 28 layers of the GLM-5 base model for two iterations with per-token gates, and Z.ai claims intelligence comparable to 2T-3T parameter models. It is live in the Z.ai Coding Plan, with API access and open weights promised later.

Auditing SWE-Gym finds 74% of unsolved tasks contain tests that reject correct fixes

A two-family LLM audit of SWE-Gym found false-negative tests in 74% of tasks a 9B base model never solves, against 20% of sometimes-solved tasks. Training on repaired tasks gains 2.4 and 2.7 points on SWE-bench Verified and SWE-bench Pro, and the authors release SWE-Gym-Verified with 1,087 audited tasks.

arXiv · 2026-11-23

PackLoop speculates only inside KV-cache rows that are read anyway

A closed-form admission rule gives token-identical output while beating the best existing per-point schedule at 161 of 164 load points across three GPUs, four Ouro models and six benchmarks, median 1.25x and up to 1.76x. The lead grows at high concurrency and long context.

arXiv · 2026-11-23

SELFWRITE lets a model write its own low-rank weight edits with no gradients

On Qwen3.8-27B, five generations of self-editing raise gate accuracy from 73.95% to 76.45% and held-out DAPO-Math accuracy from 76.30% to 77.75% (avg@4) and 82.60% to 84.80% (pass@4). The model inspects its own weights and writes the edits directly.

arXiv · 2026-11-22

Agent security scores move with the Python hash seed, not just the attack

On Agent Security Bench, changing only the hash seed altered up to 17% of an agent's verdicts across seven agents while attack success moved at most 5 points, and sorting rather than reverse-sorting the tool list raised ASR by up to 19 points. The TARE framework attributes an effect only if it exceeds measured content-free-state influence, and it reversed one defence's reported sign.

arXiv · 2026-11-23

STUN-Bench shows shared tool experience crowding out unseen tools

A split whose experience pool names none of 172 held-out tools drops routing accuracy on held-out tools from 0.534 to 0.278 under the Jina-v2 retriever. It reverses a prior conclusion that shared experience beats descriptions alone.

Seven weeks after Kolibri 1.0, the German lab published weights for a 75B-parameter MoE that activates 3.44B per token, with 262K native context extendable toward 1M and English-German tool calling. It lands amid a wave of world-model releases being evaluated as the substrate for generated games and simulations.
