Cloudflare open-sources Kitesurf, a browser engine built for AI agents

Kitesurf runs entirely on Cloudflare Workers: it parses HTML and CSS, executes page JavaScript and renders screenshots without a Chromium container. It speaks the Chrome DevTools Protocol, so clients such as Puppeteer can connect to it, and it is published on GitHub under Apache 2.0.

Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents

On ALFWorld and WebShop, a decision model used as a post-episode judge and teacher lifts a Qwen2.5-1.5B policy trained with GRPO from 72.8% to 82.9% and from 56.8% to 71.4% success, even though the same models act poorly as actors.

Open Vision Banana: a fully open recipe for generative visual perception

Trained from 4B and 9B open-weight generators on 2.1M to 3.8M public pairs, OVB beats Vision Banana's zero-shot Cityscapes result at 73.9 versus 69.9 mIoU, and its legend-ensembling test-time scaling adds up to 8.7 mIoU on Cityscapes and 15.0 on COCO-Object without retraining.

AgentSSL reframes semi-supervised learning as program search

Agents beat the strongest human-engineered SSL baselines in 8 of 12 settings by up to 21.8% under matched compute, but performance drops by as much as 47% when programs are selected via the agent's own feedback metric.

The Value of Thinking: letting a decision model choose when to reason

A self-routing block decides per query whether to answer in one forward pass or run full reasoning; HDM-4B scores 0.857 versus 0.851 on JevBench at 0.179s median latency instead of 0.652s, and HDM-27B cuts token cost 80.1% on MiniWoB.

IBM details how Granite 4.2's 3B, 8B and 30B reasoning models were built

The three dense decoder-only models were post-trained from Granite-4.1 bases on a five-phase schedule extending context to 512K, then SFT on about 7.2M samples and a staged GRPO curriculum covering math, code, science, tool use, SWE, terminal and search. All three ship under Apache 2.0 with thinking, non-thinking and low-effort modes.

NVIDIA open-sources Auto Ontology, a semantic layer for agent analytics

The Apache-2.0 Python framework builds enterprise ontologies from metadata, reconciles metric definitions across systems and exposes the result to any agent harness over MCP, CLI or API. It was the top-trending repository on GitHub today, and NVIDIA says it is not accepting external contributions.

Klein ML's KV1 trains models to survive a 2-bit KV cache

KV1-1.2B-Instruct is LFM2.5-1.2B-Instruct after quantization-aware training for a 2.5-bit KV cache, cutting cache size about 6.4x versus fp16 while retaining 75.8% of fp16 quality, where the untrained equivalent collapses to 1.6% on GSM8K.
